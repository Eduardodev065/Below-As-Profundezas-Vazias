# Below — As Profundezas Vazias

Um jogo de exploração de masmorra em pixel art, com visão de cima, combates por turnos e uma descida de até 100 andares.

## Como jogar

Baixe ou clone o repositório completo e abra `Below.exe`. Mantenha `index.html` e a pasta `assets` na mesma pasta do executável.

## Controles

- **WASD ou setas:** mover
- **Espaço:** atacar durante a batalha
- **Q:** usar a habilidade da classe
- **G:** defender durante a batalha
- **Celular:** use os controles exibidos na tela

## Tecnologias

- HTML, CSS e JavaScript
- C# no launcher para Windows

## Arquivos

- `index.html`: jogo
- `Below.exe`: inicializador para Windows
- `BelowLauncher.cs`: código-fonte do inicializador
- `assets/`: artes, ícones e sprites do jogo
