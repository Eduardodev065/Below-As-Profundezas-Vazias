BELOW — AS CINZAS DO JURAMENTO

JOGO
- O jogo roda em Electron, em tela cheia, sem abrir o navegador.
- O pacote independente inclui uma cópia portátil do Python e um runtime Java reduzido.
- Python planeja a geração procedural das camadas (tamanho, dificuldade, encontros e posições).
- Java roda como processo de gameplay e calcula movimento/fases/eventos dos chefes.
- Electron/JavaScript desenha o jogo, recebe controles e aplica colisões e efeitos visuais.
- Se o jogo for aberto diretamente como página no navegador, usa o gerador e a IA de chefes
  de reserva em JavaScript; a integração Python/Java depende do aplicativo Electron empacotado.

GERAR O EXECUTÁVEL NO WINDOWS
Execute build-windows.bat. É necessário Node.js 20+, JDK 17+ (incluindo javac e jlink)
e internet durante a compilação para baixar Electron e o Python portátil. Os jogadores
recebem o runtime dentro do Below.exe e não precisam instalar Python ou Java.
O executável fica em dist\Below.exe.

Também existe um workflow de GitHub Actions em .github/workflows/build-windows.yml.
Depois de executado, baixe o artefato Below-Windows na página Actions do repositório.

CONTROLES
WASD/setas mover | J/espaço atacar | Q habilidade | Shift esquiva | E interagir
M mapa | F/F11 tela cheia/janela | Esc/P pausa

ESTADO ATUAL
Este repositório contém o código-fonte e a receita de build. Não declarar o Below.exe
existente na pasta como build independente: ele é um launcher antigo. O pacote atualizado
precisa ser produzido pelo build-windows.bat ou pelo workflow antes de distribuição.
